### To Discuss/Resolve:
 - Luc wants to discuss: #9431
Question is: can we have Kokkos export a CMake variable exposing the status of half type (whether they are there own type or if they are `floats`)  
It is needed because currently can't be tested in Kokkos-Kernel algorithm, so can't be exported to downstream users (Trilinos, ...)  
C++23 offering extended floating point format => no need to emulate on CPU anymore  
Daniel: compiler support is not very good yet (#9253)  
Hard to detect at configure time (logic is complicated), needs to look at compiler version (duplicated logic with what we already do to define the `KOKKOS_HALF_T_IS_FLOAT` macro)  
Luc: Need to be known at configuration time in order to avoid double instantiation of templates in case float == half_t  
Daniel: Can use `KOKKOS_HALF_T_IS_FLOAT` and `check_cxx_symbol_exists` but `KOKKOS_HALF_T_IS_FLOAT` is always defined (can be true or false) => need to define a new macro name that will be define or not depending on `KOKKOS_HALF_T_IS_FLOAT` value.  
Luc: could implement it but wants Damien's opinion before starting to work on it.
