\begin{frame}[fragile]{Kokkos Tools 5.2 --- Overview}

  \textbf{Aligned release:} Kokkos Tools \textbf{5.2} ships with the Kokkos Core 5.2 cycle.

  \vspace{8pt}

  Lightweight profiling and debugging utilities that hook into Kokkos runtime instrumentation.
  Allows for Kokkos-centric analysis (kernel labels, Views) vs.\ vendor tools alone (NVTX, ROCTx, \ldots).

  \vspace{8pt}

  \begin{itemize}
    \item Load at runtime via \texttt{KOKKOS\_TOOLS\_LIBS} or \texttt{--kokkos-tools-libs}
    \item No application rebuild required (needs \texttt{Kokkos\_ENABLE\_LIBDL=ON})
    \item CMake build; C++20 required
  \end{itemize}

  \vspace{6pt}

  \textbf{Docs:} \url{https://github.com/kokkos/kokkos-tools/wiki}
  \newline
  \textbf{Repo:} \url{https://github.com/kokkos/kokkos-tools}

\end{frame}
